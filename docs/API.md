- FASTCDC algorithm (deterministic, two-level gear-hash; local-profile because spec parameters/domain are incomplete)
- CDC algorithm ID registry (LITERAL=0x00, RABIN=0x01 optional unsupported, FASTCDC=0x02, BUZHASH=0x03 optional unsupported, CUSTOM=0xF0-0xFF unsupported)
